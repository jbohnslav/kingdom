# Kingdom 1.1.0 release notes

Kingdom 1.1.0 gives agents more room to exercise judgment while keeping tickets
accurate. It replaces procedural reminders that encouraged repeated discovery
and log entries with guidance about the result the next reader needs.

## Tickets as working documents

- The core skill focuses on current purpose, scope, acceptance criteria, plans,
  and findings in the Markdown body. Agents can rewrite and reorganize it as
  understanding changes.
- Worklogs preserve meaningful history and verification evidence. They do not
  substitute for correcting the body or require a receipt after every turn.
- Known context is reused on follow-ups. Command recipes live in references
  instead of forming a repeated orientation checklist.
- Lifecycle and structured relationship changes still use kd commands for their
  validation, ownership, and context-binding behavior.

## Nonblocking reminders

Session and prompt reminders now describe outcomes rather than prescribing
create/log/defer commands. Claude and Codex Stop hooks emit an advisory UI notice
when work was observed without a ticket update, at most once per turn. They no
longer block completion or ask the agent to run `kd tk log`. Direct Markdown edits
and log entries both count as ticket updates.

Cursor Stop emits no follow-up because its only message mechanism automatically
starts another turn. Cursor's limited integration remains limited; it does not
acquire Claude/Codex reminder parity. Compaction and handoff checkpoints remain.

## Upgrade

Run `kd update` to refresh the CLI, installed skills, and an existing Codex
plugin. Start a fresh host session to use refreshed instructions. No ticket or
configuration migration is required.

## Verification

Regression tests cover advisory Stop output for Claude and Codex, suppression
after ticket updates, duplicate Stop calls, exact-ticket isolation, and the
absence of Cursor auto-followups. Release validation includes the full suite
with Textual integration, lint, CLI smoke, and built artifact checks.
