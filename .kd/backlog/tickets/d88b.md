# Align uv and pre-commit Ruff formatter versions

`uv.lock` currently resolves Ruff 0.15.0 while `.pre-commit-config.yaml` pins
`ruff-pre-commit` v0.8.6. The two formatters produce different layouts for the
same assertion expressions, so `uv run ruff format --check` can pass and the
commit hook can immediately rewrite the file in the opposite style.
