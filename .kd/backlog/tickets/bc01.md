# Peasant start preflight for uncommitted and gitignored workflow files

Peasants launched from worktrees can miss required workflow files when source changes are uncommitted or live only in gitignored paths (for example .claude/hooks). Add a preflight check in kd peasant start to detect risky state and warn or block before spawn.

## Acceptance Criteria

- [ ] `kd peasant start` checks for uncommitted changes on the hand branch before creating a worktree.
- [ ] Preflight detects when required workflow files are untracked/gitignored-only and unavailable in the target worktree.
- [ ] Default behavior is explicit warning with clear remediation; optionally support hard-block with override flag.
- [ ] Output includes concrete next step: commit/stash changes or run in hand mode.
- [ ] Automated tests cover pass, warning, and blocked/override paths.
