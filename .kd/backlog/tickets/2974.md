# Workflow friction: design phase feels wrong when working existing backlog tickets

When pulling existing backlog tickets into a branch, the design/breakdown phases feel redundant — the work is already scoped. The design phase is useful for new features where you're going from idea to tickets, but awkward when tickets already exist. Related to 3732 (optional design phase). Consider: maybe design is for epics/new features, and backlog sprints skip straight to execution.
