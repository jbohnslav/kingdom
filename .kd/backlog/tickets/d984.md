# Add shortcut command for interactive ticket work (kd work)

When working a ticket interactively (--hand mode), the user currently has to copy-paste the full peasant command. Add a convenience command (e.g. kd work <id>) that starts a peasant in --hand mode for the given ticket. Shorter to type, easier to remember than 'kd peasant start <id> --hand'.
