# Give agent sessions automatic role-flavored display names

Optionally assign memorable generated display names to agent sessions without using
those names as durable identity. Directly supervised agents could receive
noble-sounding names; autonomous peasants could receive deliberately rustic names.
Keep the tone configurable so serious environments can use neutral names.

## Acceptance Criteria

- [ ] Generated names are presentation-only and never replace stable host/session IDs.
- [ ] Noble, peasant, and neutral vocabularies are distinct and non-derogatory.
- [ ] Names are unique within an active project and remain stable for the session.
- [ ] Users can disable generated names or supply an explicit display name.
- [ ] Status, TUI, and worklog attribution show the name without obscuring role or ticket.
