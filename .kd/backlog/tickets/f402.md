# kd tk start should set assignee so Hand-worked tickets are distinguishable

kd tk start sets status to in_progress but doesn't set an assignee. Peasant start sets assignee: peasant-<id>, but the Hand has no equivalent. This blocks: (1) lord knowing not to start a peasant on a Hand-worked ticket, (2) hooks targeting the right ticket, (3) list/status showing who's working what. Fix: kd tk start should set assignee: hand (or derive from session context).

## Acceptance Criteria

- [ ] kd tk start sets assignee field
- [ ] kd tk list shows assignee for in_progress tickets
- [ ] Lord/hooks can distinguish Hand-assigned from peasant-assigned tickets
