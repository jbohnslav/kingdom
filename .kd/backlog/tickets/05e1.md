# DuplicateIds crash: wait-claude WaitingPanel mounted when one already exists

## Description

`DuplicateIds` error when mounting a `WaitingPanel` with `id='wait-claude'` while one already exists in the DOM. Likely happens when `send_message()` or `run_chat_round()` mounts a new `WaitingPanel` without the prior one being fully removed (race between `remove_member_panels()` and async mount).

Error: `DuplicateIds: Tried to insert a widget with ID 'wait-claude', but a widget already exists with that ID (WaitingPanel(id='wait-claude'))`

## Likely cause

`remove_member_panels()` calls `panel.remove()` which is async — the widget may still be in the DOM when the next `log.mount(WaitingPanel(...))` runs synchronously. Or a poll cycle mounts a panel between the cleanup and the new mount.
