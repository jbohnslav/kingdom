# Multiline tk log should not emit trailing whitespace

During post-1.0.0 dogfooding, a multiline stdin entry written with
`uv run kd tk log` indented blank continuation lines with spaces. The resulting
ticket failed `git diff --check` and required a manual Markdown cleanup.

## Acceptance Criteria

- [ ] Multiline worklog entries contain no whitespace-only lines.
- [ ] A regression passes a note containing blank lines through `kd tk log` and
  verifies the ticket with `git diff --check` or an equivalent whitespace assertion.
