# kd peasant accept should auto-clean worktree after successful merge

`kd peasant accept` merges and closes the ticket but leaves the worktree directory and branch behind. There's no reason to keep a worktree after a successful accept — it should be cleaned up automatically as part of the accept flow. This affects both the lord and manual usage.

## Acceptance Criteria

- [ ] `kd peasant accept` removes the worktree and deletes the ticket branch after successful merge + close
- [ ] Cleanup failure (e.g. worktree already removed) is a warning, not an error — the accept still succeeds
- [ ] No separate `kd peasant clean` step needed after accept
