# Add sample input-output pairs to the kingdom skill

The kingdom skill (skills/kingdom/SKILL.md) needs concrete input-output examples so the agent knows exactly what kd commands to run for common requests. Right now the skill describes capabilities but lacks worked examples showing the user's words mapped to the exact kd invocation.

Add a section of sample pairs like:
- "update the worklog" → kd tk log abc1 "I ran the script and it errored out. I need to add a unit test to reproduce..."
- "close the ticket" → kd tk close abc1
- "start a new feature" → git checkout -b feature-name && kd start
- "ask the council about X" → kd council ask "What do you think about X?"
- "create a backlog ticket" → kd tk create --backlog "title"
- "make a p1 backlog ticket about X" → kd tk create --backlog -p 1 -d "description" "title"
- etc.

The goal is that the agent gets the CLI invocation right on the first try every time, without needing to run `--help` first. Cover the full range of common workflows so the agent can pattern-match natural language to the right command with realistic arguments and flags.
