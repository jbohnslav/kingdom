# Native subagents should get distinct kd execution contexts

During post-1.0.0 dogfooding, a spawned Codex subagent inherited the root
`CODEX_THREAD_ID`. Its first `uv run kd tk start` resolved the same execution
context and temporarily transferred the root worker's ticket binding. The agent
recovered only by supplying a unique `KD_CONTEXT` explicitly.

## Acceptance Criteria

- [ ] Native subagents receive distinct execution identities without requiring manual environment overrides.
- [ ] Starting a ticket in a child cannot silently unbind or reassign its parent's active ticket.
- [ ] Regression coverage exercises parent and child contexts that inherit the same host thread environment.
