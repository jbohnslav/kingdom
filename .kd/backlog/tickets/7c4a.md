# Bug: CLI error messages print twice (print_error + typer echo duplication)

## Description

Many CLI commands use `print_error("message")` followed by `raise typer.Exit(code=1)`. The error message appears twice in the terminal — once from `print_error` (Rich console to stderr) and once from Typer's error output. Reproduced with `kd tk link aaaa` and `kd tk link A A`.

Pre-existing issue across the codebase, not specific to any one command.

## Acceptance Criteria

- [ ] Error messages display exactly once
- [ ] Consistent pattern for error handling across all commands
