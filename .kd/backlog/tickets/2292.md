# Make tk list --all account for archived open tickets

`uv run kd tk list --all --include-done` describes itself as listing tickets
across all locations, but it omits open ticket files in legacy archived
workspaces. During the 2026-08-19 inventory it reported 16 open tickets while a
raw ticket scan also found archived open tickets `10ee` and `41f9`.

## Acceptance Criteria

- [ ] The meaning of `--all`, `--include-done`, and archive inclusion is explicit and internally consistent.
- [ ] Users can list archived open tickets without raw filesystem inspection.
- [ ] Human and JSON output agree about locations and counts.
- [ ] Regression coverage includes an archived workspace containing an open ticket.
