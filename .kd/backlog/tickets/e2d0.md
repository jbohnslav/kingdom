# Let kd start bootstrap a fresh workspace

## Acceptance Criteria

- [ ] `kd start <branch>` can create the initial `.kd` layout in a fresh project,
  or the CLI provides a discoverable initialization command.
- [ ] The command's help text accurately describes whether it initializes or
  only resumes existing Kingdom state.

## Context

The concurrent-session dogfood script failed in a fresh temporary directory:
`kd start dogfood/concurrent` reported that the directory did not contain
`.kd`, while `kd init --help` reported that no such command exists. Creating an
empty `.kd/` manually allowed `kd start` to proceed.
