# Make kd done safe for non-interactive callers

`kd done` has an interactive `typer.confirm()` when worktrees exist that blocks non-interactive agents (lord, peasants, scripts). The `--force` flag skips this but also skips the open-ticket check, which is a separate concern.

When stdin is not a TTY, skip the worktree-removal confirmation automatically. Keep `--force` for its current purpose (skipping the open-ticket check).

## Acceptance Criteria

- [ ] `kd done` skips worktree-removal confirmation when stdin is not a TTY
- [ ] `kd done` still prompts for worktree removal when stdin IS a TTY (current behavior preserved)
- [ ] `kd done` still blocks on open tickets regardless of TTY status (unless `--force`)
- [ ] `--force` continues to skip both the open-ticket check and confirmation
