# Dogfood: run lord on a real epic and file follow-up bugs

Use the lord to run a real epic (could be a batch of backlog tickets or a small feature epic). The goal is to validate the design end-to-end: does massive parallelism surface conflict issues? Does cross-ticket review catch real problems? Does the epic worklog give the King enough visibility? Does the lord handle edge cases (peasant failures, merge conflicts, dependency chains) gracefully? Document what breaks, file follow-up backlog tickets for anything that needs fixing.

## Acceptance Criteria

- [ ] Lord successfully ran on a real epic with multiple parallel peasants
- [ ] Cross-ticket integration review exercised on at least one accept
- [ ] At least one merge conflict encountered and resolved (or documented if none arose naturally)
- [ ] Follow-up bugs/improvements filed as backlog tickets
- [ ] Brief summary of what worked and what didn't logged to the epic worklog
