# Fix stale council status in peasant watch

kd peasant watch / poll_council_status scans any branch-level council thread with leftover .stream-*.jsonl files and can report stale statuses like 'claude responded, codex errored' that are unrelated to the active peasant review. This is confusing when the actual work thread review later completes with real reviewer messages. Narrow the watch signal to the relevant review context or clean up stale stream files so the status line reflects the current peasant review only.
