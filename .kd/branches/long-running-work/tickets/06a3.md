# Add --json output to agent-facing kd commands

Agents (lord, peasants, the Hand) constantly parse rich table output. Add `--json` to all commands that agents commonly consume. This is foundational for lord mode but also improves the experience for any agent-driven workflow.

Commands already with --json: `kd tk list`, `kd tk show`, `kd tk current`, `kd status`, `kd council ask`.

## Acceptance Criteria

- [ ] `kd peasant status --json` outputs JSON (must include effective status — report "dead" not "working" for dead processes)
- [ ] `kd peasant show --json` outputs JSON
- [ ] `kd council list --json` outputs JSON
- [ ] `kd council status --json` outputs JSON
- [ ] `kd deps tree --json` outputs JSON
