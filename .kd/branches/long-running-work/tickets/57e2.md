# Redundant discover_epic_children calls in lord prompt building

build_lord_prompt calls discover_epic_children once directly, then each of get_startable_children, get_completed_peasants, get_active_peasants calls it again internally — 4+ redundant directory scans and ticket re-reads per cycle. The helpers also re-read the same tickets that build_lord_prompt already parsed. Refactor to discover children once and pass the list through, and consider caching the parsed ticket data across helpers.

## Acceptance Criteria

- [ ] discover_epic_children is called once per lord cycle, not per-helper
- [ ] Parsed ticket data is reused across prompt building, not re-read from disk
