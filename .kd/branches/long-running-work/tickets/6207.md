# Fix --ready filter to exclude custom statuses like blocked

The --ready filter only excludes in_review and closed. With arbitrary statuses via kd tk status (e.g. blocked, waiting), those tickets still appear as ready. Fix: --ready should only include tickets with status open or in_progress.

## Acceptance Criteria

- [ ] --ready only shows tickets with status open or in_progress
- [ ] Tickets with custom statuses (blocked, waiting, etc.) are excluded from --ready
