# Chat TUI: show tool use and progress updates during agent responses

## Description

Surface tool-use events and progress updates in the chat TUI during agent responses. When an agent reads a file, runs a command, etc., show a brief status line in the streaming panel (e.g., "reading file.py", "running pytest").

Add `extract_stream_tool_use()` per-backend extractors in `agent.py` (same pattern as `extract_stream_text` / `extract_stream_thinking`), a new `ToolUseEvent` in `poll.py`, and render it in the chat TUI.

Stream formats:
- Claude Code: `stream_event` wrapping `content_block_start` with `type: "tool_use"` + input deltas
- Cursor: `{"type": "tool_call", "subtype": "started", ...}` with tool name and args
- Codex: `item.completed` events — investigate tool-use item types from sample logs in `.kd/` as first step

## Acceptance Criteria

- [ ] `extract_stream_tool_use()` extractors for claude_code and cursor backends
- [ ] `ToolUseEvent` dataclass in `poll.py` (member, tool_name, args summary)
- [ ] `tail_stream_file()` extracts tool-use events alongside text and thinking
- [ ] Chat TUI renders tool-use as a brief status line in or below the streaming panel
- [ ] Codex tool-use format investigated and documented (extractor added if format is clear)
- [ ] Test: tool-use extraction from sample NDJSON lines per backend
