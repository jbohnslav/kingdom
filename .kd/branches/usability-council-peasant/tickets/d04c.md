# Add --verbose/-v flag to kd commands for debug output (file paths, log level, etc.)

## Description

Add a global `--verbose` / `-v` flag on the root `kd` Typer app. When set, print debug output: resolved file paths, config source, log level. Implement early — useful as a dev aid while building other tickets.

## Acceptance Criteria

- [ ] `--verbose` / `-v` flag on root `kd` app via Typer callback
- [ ] Sets a module-level verbose flag accessible by all commands
- [ ] `kd council ask -v` shows: resolved config path, member agents, thread path, stream file paths
- [ ] `kd peasant start -v` shows: worktree path, ticket path, harness config
- [ ] `kd config show -v` shows: config file path and load source
- [ ] Flag is silent when not set (no output change for normal usage)
- [ ] Test: verbose flag is parsed and accessible
