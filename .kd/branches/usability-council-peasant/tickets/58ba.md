# Council review feedback: workflow-friction branch fixes

Council review of the workflow-friction branch surfaced these issues.

## Fixes

1. **Bug: dead ternary in cmd_copy** (app.py:859) — Both branches produce the same `f" from {last.from_}"` string. The `if member_filter` check does nothing.

2. **Crash: dep-tree --full infinite recursion on cycles** (cli.py) — The `seen` guard is only active when `full=False`. Running `kd tk dep-tree A --full` on cyclic deps (A→B→A) causes `RecursionError`. Fix: keep cycle protection in --full mode, show a marker instead of descending.

3. **Misleading: "completed" label hides failed/stopped peasants** (cli.py) — `TERMINAL_STATUSES = {"done", "failed", "stopped"}` but the user-facing message only says "N completed". Should say "N hidden" or list the breakdown.

4. **tk closed silently omits done branches** (cli.py/ticket.py) — `collect_all_tickets` skips done branches, so closed tickets in archived branches are invisible. Either include done branches for `tk closed` or document the exclusion.

5. **tk link allows self-links and duplicates** (cli.py) — `kd tk link aaaa aaaa` creates a self-link. Deduplicate resolved IDs and reject self-link.

6. **dep-cycle includes closed tickets despite docstring** (cli.py) — Help says "among open tickets" but traverses all. Filter to non-closed or update docs.

7. **Config docs: preamble constraint** — docs/config.md says default is empty, but validator rejects explicit empty string. Document "if specified, must be non-empty."

## Test Gaps

- dep-tree --full with cycle should not crash
- tk closed should test done-branch behavior

## Excluded (not bugs)

- **kd done partial state** — confirmation is about worktree cleanup, not about marking done. Saying "no" keeps worktrees but session is correctly done.
- **render_ticket_panel perf** — premature optimization at current scale.
- **ticket_query excludes closed** — intentional; `kd tk list --json --include-closed` already covers this.

## Worklog

  - **Bug 4**: `tk closed` now includes done branches via `collect_all_tickets(include_done=True)`. Added `include_done` param to `collect_all_tickets`.
  - **Bug 5**: `tk link` deduplicates resolved IDs and rejects self-links with a clear error.
  - **Bug 6**: `dep-cycle` now filters to non-closed tickets only, matching its docstring.
  - **Bug 7**: Updated `docs/config.md` preamble default from `""` to `*(none)*` with note "must be non-empty if specified".
