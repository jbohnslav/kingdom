# Rethink peasant observability: work logs, watch diffs, and tmux mode

## Problem

Peasant work is a black box. You kick one off and have no idea what's happening until it's done (or broken).

## Three pieces (per design)

**R4a — Continuous work logs**: Make the harness append to the ticket work log continuously during each iteration, not just at completion. This is a contract change in the harness loop.

**R4b — `kd peasant watch <id>`**: New command under `kd peasant`. Tail-like CLI stream showing work log appends, diffs, ticket updates in real time. Exits on Ctrl+C or when peasant finishes.

**R4c — Tmux mode**: `kd peasant start --tmux <id>` opens the agent in a new tmux window so you can watch it work like regular Claude Code. Error if tmux is not running.

## Acceptance Criteria

- [ ] Peasants append to work log continuously as they work, not just at completion
- [ ] `kd peasant watch <id>` shows real-time progress (work log entries, diffs, ticket updates)
- [ ] `kd peasant watch` exits on Ctrl+C or when peasant finishes
- [ ] `kd peasant start --tmux <id>` opens agent in a new tmux window
- [ ] `--tmux` errors clearly if tmux is not running
