# Add kd update command: self-upgrade CLI + refresh skill files

Add a top-level kd update command that does two things in sequence: (1) runs `uv tool upgrade kingdom-cli` to update the installed CLI, and (2) calls `install_skill()` to refresh the Claude skill files. This eliminates the need to run `kd start --force` after upgrading, which conflates session lifecycle with maintenance. The command should report what it did (upgrade result, skill files refreshed). Keep `install_skill()` running automatically in `kd start` as well — `kd update` is the explicit recovery/upgrade path.

## Acceptance Criteria

- [ ] kd update runs `uv tool upgrade kingdom-cli` and reports the result
- [ ] kd update calls install_skill() to refresh skill files after upgrade
- [ ] kd update prints a summary of what it did (upgrade result, skill status)
- [ ] kd start still auto-refreshes skill files (no regression)
- [ ] kd update appears in kd --help output
