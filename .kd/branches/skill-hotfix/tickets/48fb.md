# Replace `kd peasant logs` with `kd peasant show`

`kd peasant watch` shows rich, structured progress: iteration counts, file edits, agent reasoning snippets, worktree diffs, and commit detection. But there's no way to get that same content after the fact — `kd peasant logs` only dumps raw stdout.log/stderr.log which contain almost nothing useful.

Decision (council thread council-952f, King's call): replace `logs` with `show` to match the existing pattern (`kd tk show`, `kd council show`). No filtering flags — keep it simple. Structured report, not a replay of `watch`.

`show` should render:
- Worklog entries with timestamps
- Agent activity from agent-live.log (filtered through existing helpers)
- Commit summaries
- Skip heartbeat/filler lines ("Still working...")

## Acceptance Criteria

- [ ] `kd peasant show <id>` renders full structured history (worklog + agent activity + commits)
- [ ] `kd peasant logs` is removed
- [ ] Works after the peasant has finished (not just live)
- [ ] Update skill docs and help text referencing `logs` → `show`
