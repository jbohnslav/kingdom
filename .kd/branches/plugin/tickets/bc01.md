# Peasant start preflight for uncommitted and gitignored workflow files

Peasants launched from worktrees can miss required workflow files when source changes are uncommitted or live only in gitignored paths (for example .claude/hooks). Add a preflight check in kd peasant start to detect risky state and warn or block before spawn.

## Acceptance Criteria

- [ ] `kd peasant start` copies `.claude/settings.json` into the worktree after creation via `sync_workflow_files()` in `worktree.py`
- [ ] Preflight warns (not blocks) on uncommitted changes, with concrete next step (commit/stash or use `--hand`)
- [ ] `--no-preflight` flag suppresses the uncommitted-changes warning
- [ ] All preflight checks skipped in `--hand` mode
- [ ] Fail-open in non-git contexts (no crash if git isn't available)
- [ ] Tests cover sync, uncommitted warning, `--no-preflight`, `--hand` skip, and fail-open
