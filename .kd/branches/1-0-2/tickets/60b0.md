# Make kd status surface Git and Kingdom branch mismatch after checkout

When the checked-out Git branch has no matching Kingdom workspace, `kd status`
currently falls back to `.kd/current` and presents the previous workspace without
explaining the mismatch. Surface the discrepancy without changing workspace
selection or readiness semantics.

## Acceptance Criteria

- [x] Human-readable `kd status` warns when the checked-out Git branch differs from the resolved Kingdom workspace.
- [x] The warning names both branches and recommends `kd start <git-branch>`.
- [x] JSON status output exposes the checked-out Git branch and mismatch state.
- [x] Matching or unavailable Git branch information does not produce a false warning.
