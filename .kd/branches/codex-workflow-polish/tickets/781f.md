# Add explicit resolutions to the existing kd tk close

`kd tk close` already supports an optional reason, `closed_at`, and
`--duplicate-of`; keep that good interface and extend it. A closed ticket should
say whether work was completed, won't-do, duplicate, superseded, or invalid—not
merely disappear from the ready queue.

## Acceptance Criteria

- [x] Frontmatter gains a backwards-compatible `resolution` field with a small documented enum.
- [x] `kd tk close ID` defaults to `completed` and supports explicit non-completed resolutions.
- [x] Non-completed resolutions require a non-empty close reason.
- [x] Closing records actor/context and timestamp and clears active bindings atomically.
- [x] Invalid transitions fail with useful recovery guidance.
- [x] Existing `--reason`, `--duplicate-of`, `closed_at`, and archive behavior remain compatible.
