# Bind kd tk start and current to the active execution context

Replace "first in-progress ticket on this branch" with an exact binding for the
calling context. Branch membership remains useful organization, but not identity.

## Acceptance Criteria

- [ ] `kd tk start ID` assigns the ticket to the resolved execution context.
- [ ] `kd tk current` returns only that context's ticket and never guesses among peers.
- [ ] An unbound context gets a concise recovery message with explicit next actions.
- [ ] An intentional context override works for hooks and test automation.
- [ ] Starting, switching, closing, and reopening tickets update bindings atomically.
- [ ] CLI output is manually inspected in two simultaneous terminals.
