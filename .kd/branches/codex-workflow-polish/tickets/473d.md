# Build upgrade, rollback, and doctor support for existing .kd repositories

Use real repository shapes—including Kingdom's own long history—to make upgrades
boring and recoverable.

## Acceptance Criteria

- [ ] Migration fixtures include backlog, active, archived, old context, and partially written state.
- [ ] Upgrade is idempotent and preserves every ticket's Markdown content and ID.
- [ ] A rollback/backup path is documented and exercised.
- [ ] `kd doctor` detects ambiguous bindings, orphan contexts, bad resolutions, and stale host installs.
- [ ] Doctor suggests exact non-destructive repairs and never silently rewrites user content.
