# Test three to five concurrent sessions on one branch

Exercise the exact daily failure mode: several agents and terminals, one branch,
different tickets, interleaved starts/logs/stops.

## Acceptance Criteria

- [ ] An integration test creates at least five contexts on one branch with distinct tickets.
- [ ] Each context's `current`, log target, status row, and close behavior stays isolated.
- [ ] Reused terminals, ended sessions, and stale bindings are covered.
- [ ] At least one test spans two host identity formats.
- [ ] A manual reproduction script records readable CLI output for release evidence.
