# Structure close reasons, lifecycle history, and reopen behavior

The current close reason is already preserved as a worklog entry. Add structured,
queryable closure evidence without sacrificing that readable history, so later
agents understand why work ended and can reopen without erasing it.

## Acceptance Criteria

- [x] Close reason and resolution appear in `show`, list/JSON where requested, and ticket Markdown.
- [x] A lifecycle section records close and reopen events append-only.
- [x] Reopen clears the active terminal resolution while preserving prior events.
- [x] Duplicate/superseded resolutions can reference another ticket.
- [x] Filters can distinguish completed from other closed work.
