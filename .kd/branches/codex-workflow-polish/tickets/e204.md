# Define portable execution-context identity and storage

Define the smallest stable identity that distinguishes simultaneous agent sessions without
making a git branch, terminal TTY, or one vendor's session ID authoritative.

## Acceptance Criteria

- [x] A context schema includes host, stable session ID, optional parent agent ID, cwd, and last-seen time.
- [x] Resolution order covers explicit `KD_CONTEXT`, hook `session_id`, `CODEX_THREAD_ID`, and terminal fallbacks.
- [x] IDs are namespaced by host to prevent collisions and never contain secrets or full prompts.
- [x] Context-to-ticket bindings use an atomic, human-inspectable format under `.kd`.
- [x] Pure unit tests cover missing, conflicting, and stale identifiers.
