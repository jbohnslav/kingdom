# Normalize host hook events around session, context, and provenance

Create one narrow internal event model so Claude, Codex, Cursor, and future hosts
do not leak vendor payload shapes into ticket logic.

## Acceptance Criteria

- [ ] Typed events cover session start/end, pre/post compact, subagent start/stop, prompt submit, and stop where available.
- [ ] Adapters normalize host, session, agent, parent-agent, cwd, event, and optional ticket hint.
- [ ] Unknown fields are ignored safely; malformed required fields fail loudly in diagnostics.
- [ ] Ticket mutation consumes normalized events only.
- [ ] Fixtures are derived from documented host payloads without storing user content.
