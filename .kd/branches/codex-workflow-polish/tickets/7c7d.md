# Make kd done report and validate terminal resolutions

Keep `kd done` as the branch/release guard, but make its output reflect real
outcomes rather than treating every closed item as identical.

## Acceptance Criteria

- [x] `kd done` accepts every valid terminal resolution and rejects unresolved tickets.
- [x] Output summarizes counts by resolution and calls out won't-do/duplicate/superseded work.
- [x] Missing required reasons or references fail validation.
- [x] JSON and human output agree.
- [x] Existing repositories without resolutions receive a documented compatibility interpretation.

  `superseded-by`; unknown or mismatched evidence fails even with `--force`.
