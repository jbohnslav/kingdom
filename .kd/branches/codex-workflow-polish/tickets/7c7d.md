# Make kd done report and validate terminal resolutions

Keep `kd done` as the branch/release guard, but make its output reflect real
outcomes rather than treating every closed item as identical.

## Acceptance Criteria

- [ ] `kd done` accepts every valid terminal resolution and rejects unresolved tickets.
- [ ] Output summarizes counts by resolution and calls out won't-do/duplicate/superseded work.
- [ ] Missing required reasons or references fail validation.
- [ ] JSON and human output agree.
- [ ] Existing repositories without resolutions receive a documented compatibility interpretation.
