# Dogfood three to five concurrent hands on one branch

Run the user's actual working pattern, not just synthetic unit tests, and preserve
the evidence in this ticket's worklog.

## Acceptance Criteria

- [ ] Three to five real terminal/agent sessions bind different tickets on the same branch.
- [ ] Each session starts, queries, logs, checkpoints, and closes without cross-writing.
- [ ] Status and TUI make the active work understandable at a glance.
- [ ] At least one session ends/restarts and one binding becomes stale.
- [ ] Every confusing output or workaround becomes a backlog ticket before this closes.
