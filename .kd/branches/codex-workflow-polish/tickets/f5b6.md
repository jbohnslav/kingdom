# Checkpoint tickets before compaction and at session handoff

Turn the user's manual "thoroughly update your ticket" instruction into a host
lifecycle behavior wherever a reliable pre-compaction or session-end hook exists.

## Acceptance Criteria

- [ ] Pre-compaction asks the active agent to record decisions, completed work, verification, blockers, and next steps.
- [ ] Session-end produces the same structured handoff when the host permits agent output.
- [ ] The checkpoint targets the exact context binding and never the most recent branch ticket.
- [ ] Repeated hook calls are idempotent enough to avoid duplicate boilerplate.
- [ ] Hook timeouts/failures warn but do not block compaction or session exit.
- [ ] Hosts without a pre-compaction interception point have a documented manual fallback.
