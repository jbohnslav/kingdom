# Prevent kd start from swallowing legacy repository-state errors

`kd start` catches the same `ValueError` used for both "no repository found" and
the deliberate legacy `.kd/runs` compatibility guard, then falls through to
auto-initialization. Preserve the explicit repository-state error instead of
presenting a misleading fresh-repository path.
