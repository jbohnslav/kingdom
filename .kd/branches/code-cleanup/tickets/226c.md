# kd tk list: show dep status (open/closed) in Deps column

Currently the Deps column shows bare ticket IDs like '5afc, ffc8'. You can't tell whether those deps are satisfied (closed) or still blocking. This caused confusion — tickets with all deps closed looked blocked. Fix: annotate each dep with status, e.g. '5afc ✓, ffc8' or '5afc (closed), ffc8 (open)', or hide satisfied deps entirely and only show open blockers.
