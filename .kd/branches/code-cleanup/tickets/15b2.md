# Fix global mutable state (R7)

## Problem

The module-level `VERBOSE: bool = False` global in `cli/helpers.py` is mutable
shared state. The `app_callback()` in `cli/__init__.py` sets it in two places
(the module global AND the helpers module attribute) which is fragile and
error-prone. Replace with Typer's context object.

## Scope

This is a small, mechanical refactor. The only global to remove is `VERBOSE`.
The only consumer is `verbose_echo()`. There are ~12 call sites across 3 CLI
modules (`peasant.py`, `council.py`, `config.py`) — they all call
`verbose_echo(msg)` and don't need to change.

## Implementation

1. In `cli/__init__.py`, change `app_callback()` to store verbose on Typer's
   context: `ctx.ensure_object(dict)["verbose"] = verbose`. Remove the
   `global VERBOSE` and the `_helpers.VERBOSE = verbose` lines.

2. In `cli/helpers.py`, remove the `VERBOSE: bool = False` module global.
   Change `verbose_echo()` to get the flag from Typer context:
   ```python
   def verbose_echo(message: str) -> None:
       import typer
       ctx = typer.Context.get_current(silent=True)
       if ctx is None or not ctx.ensure_object(dict).get("verbose"):
           return
       ...
   ```
   The `silent=True` + None check means verbose_echo is safe to call outside
   of a Typer command context (e.g. from tests or harness code) — it just
   silently does nothing.

3. Remove the `VERBOSE` re-export from `cli/__init__.py`. Check that nothing
   imports it directly. If tests reference `VERBOSE`, update them.

4. That's it. Don't create a context dataclass, don't add middleware, don't
   refactor the callback system. This is plumbing, not architecture.

## Acceptance Criteria

- [ ] Module-level `VERBOSE` global removed from `cli/helpers.py`
- [ ] `global VERBOSE` and dual-write removed from `cli/__init__.py`
- [ ] `verbose_echo()` reads from Typer context via `ctx.ensure_object(dict)`
- [ ] `verbose_echo()` is safe to call outside Typer context (no crash)
- [ ] All ~12 `verbose_echo()` call sites unchanged
- [ ] `VERBOSE` no longer exported from `cli/__init__.py`
- [ ] All tests pass
