# Rethink peasant observability: work logs, watch diffs, and tmux mode

## Problem

Peasant work is a black box. You kick one off and have no idea what's happening until it's done (or broken). The current `kd watch` doesn't give enough visibility into what the agent is actually doing — you can't see the prompts it was given, its tool calls, the files it's editing, none of it.

## Ideas

1. **Work logs as a hard requirement** — Peasants should append to their work log by default as they work, not just at the end. Make this a stronger contract so there's always a trail of what happened.

2. **Watch shows everything** — `kd watch` should stream all activity: diffs into the work log, ticket updates, code changes. You should be able to see the peasant's progress in real time, not just poll for a final result.

3. **Optional tmux mode** — Instead of (or in addition to) the file-based watch, offer a mode where `kd peasant start` opens the agent in an actual shell (tmux pane/window) so you can watch it work like regular Claude Code. This gives full interactive visibility without reinventing a terminal UI.

4. **Council review details** — When a peasant gets council review, the logs just say "1 approved, 1 blocked" with no context. You can't see what the peasant asked the council, or why a member blocked. The review prompt and each member's reasoning should be visible in the work log / watch output.

### What it actually looks like today

```
- [13:19] — Iteration 1/50 — calling agent
- [13:22] — ## What I did this iteration
- [13:26] — Council review: BLOCKING (bounce 1/3) — returning to working
- [13:26] — Iteration 2/50 — calling agent
- [13:28] — ## What I did this iteration
- [13:29] — Council review: APPROVED — awaiting king review
```

No idea what the agent did. No idea what the council reviewed. No idea why it was blocked the first time, or what changed to get it approved the second time. Just vibes.

## Acceptance Criteria

- [ ] Peasants append to work log continuously as they work, not just at completion
- [ ] `kd watch` shows meaningful real-time progress (diffs, log entries, ticket updates)
- [ ] Investigate tmux mode: `kd peasant start --tmux <id>` opens agent in a visible tmux pane
