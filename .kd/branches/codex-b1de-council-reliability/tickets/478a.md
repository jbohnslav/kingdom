# Make council review handle or explain uncommitted changes

kd council review --base master reports 'No changes between master and HEAD' when the branch has a substantial uncommitted working-tree diff. Expected: include staged/unstaged changes in a pre-commit review, or clearly state that only committed changes are reviewed and tell the user how to proceed.

## Acceptance Criteria

- [x] `kd council review` dispatches when the review target contains only staged or unstaged tracked changes.
- [x] The changed-files summary covers committed and working-tree changes from the branch merge-base without changing commit-log scope.
- [x] The review prompt explicitly tells Council members how to inspect staged and unstaged changes.
- [x] An untracked-only repository does not dispatch an incomplete review and prints bounded path-only recovery guidance.
- [x] Mixed tracked and untracked changes dispatch the review with a clear warning that untracked files are excluded.
- [x] Focused regression tests, Ruff checks, diff validation, and a manual CLI check pass.
