# Fold workspace switching into kd start

Use the already-idempotent `kd start [branch]` as the single command for
initializing, resuming, or selecting a workspace. Remove the redundant public
switch operation.

## Acceptance Criteria

- [x] `kd start <branch>` selects an existing workspace as the repository fallback.
- [x] Starting a legacy done workspace deliberately reactivates it without disturbing ticket history.
- [x] The top-level `kd switch` command is removed.
- [x] Execution-context ticket bindings remain independent from the repository fallback.
- [x] Focused tests are written red-first and pass after implementation.
