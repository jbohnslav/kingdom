# Make kd tk show LLM-friendly and prefer direct ticket Markdown edits

kd tk show currently renders tickets inside a Rich frame/table-style layout. That is useful for humans but poor for LLM agents because the raw Markdown is hidden behind wrapped terminal formatting. Agents also currently use kd tk log / command-mediated edits repeatedly, which can conflict with file-edit tooling that requires reading a file before editing; direct Markdown edits allow edit -> edit -> edit workflows without that failure mode. Expected: provide an LLM-friendly/raw Markdown way to view tickets and document that agents should edit ticket Markdown directly when making repeated ticket body/worklog changes.

## Acceptance Criteria

- [x] `kd tk show <id>` prints raw ticket Markdown without Rich frame characters by default
- [x] Existing framed ticket display remains available for humans
- [x] Agent-facing workflow guidance prefers direct ticket Markdown edits for repeated ticket updates
- [x] Tests cover the raw default and preserved rich display
