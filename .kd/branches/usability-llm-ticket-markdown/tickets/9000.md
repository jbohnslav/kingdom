# Add title and body aliases for ticket creation

Agents often try to create tickets with explicit -t/--title and -b/--body flags instead of one positional title plus -d/--description. Support that ergonomic form without breaking existing create flags.

## Acceptance Criteria

- [x] `kd tk create --title "..." --body "..."` creates a ticket without requiring a positional title
- [x] `kd tk create -t "..." -b "..."` creates a ticket without requiring a positional title
- [x] Existing positional title usage remains supported
- [x] Existing `kd tk create "Title" -t bug` shorthand remains supported for ticket type compatibility
- [x] `--type` is available as the explicit ticket type flag
- [x] Conflicting title/body inputs fail with clear errors
