# Prefer tmux pane identity for terminal ticket context

Claude re-review found terminal_context_identity checks TERM_SESSION_ID/ITERM_SESSION_ID before TMUX_PANE/STY. Under tmux panes launched from one terminal window, the outer terminal session id can be shared across panes, so kd tk start in one pane can overwrite another pane's terminal ticket context and the Stop hook can prompt for the wrong ticket.

## Acceptance Criteria

- [x] terminal_context_identity prefers multiplexer pane identifiers over shared outer-terminal identifiers
- [x] Regression test covers shared TERM_SESSION_ID with distinct TMUX_PANE values
