# Use KD_BASE when reading terminal ticket context

Codex review found that the Stop hook reads terminal ticket context from CLAUDE_PROJECT_DIR, while kd tk start writes terminal context under the Kingdom project root/KD_BASE. In sibling worktrees this can miss the per-terminal record and fall back to kd tk current, reintroducing wrong-ticket behavior for multiple hands.

## Acceptance Criteria

- [x] Stop hook reads terminal ticket context from the same Kingdom root used by kd tk start, including KD_BASE worktree contexts
- [x] Regression test covers CLAUDE_PROJECT_DIR worktree plus KD_BASE main repo
