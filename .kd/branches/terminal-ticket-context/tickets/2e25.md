# Do not require worklog for ticket-only edits

The Stop hook currently treats editing a ticket Markdown file as meaningful work that must be followed by kd tk log. That is noisy when the only durable work was the ticket update itself: the ticket file is already the log/source of truth, so the hook should not block just because an agent edited only .kd ticket markdown.

## Acceptance Criteria

- [x] Stop hook does not block when the only work tools edited ticket markdown files
- [x] Stop hook still blocks when code or non-ticket files were edited without a worklog
- [x] Regression tests cover ticket-only edits and mixed ticket-plus-code edits
