# Make log hook prefer terminal-local last started ticket

The log hook often fails to infer the correct ticket when several terminal windows or hands are active. It should prefer the last ticket started with kd tk start in the same terminal window, so each hand gets terminal-local ticket context instead of competing global inference.

## Acceptance Criteria

- [ ] kd tk start records the started ticket in terminal-local state
- [ ] The log hook prompt tells agents to prefer the terminal-local last-started ticket
- [ ] Tests cover separate terminal windows getting different active ticket hints
