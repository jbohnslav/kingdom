# Install Kingdom skill for Cursor when Cursor config exists

Install the bundled Kingdom skill into Cursor when Cursor is present.

Behavior:
- Detect Cursor by the presence of ~/.cursor.
- Install/refresh the skill at ~/.cursor/skills/kingdom/SKILL.md with references copied beside it.
- Create ~/.cursor/skills/kingdom even when ~/.cursor/skills does not already exist.
- Do nothing when ~/.cursor is absent.
- Preserve dev-symlink behavior for the specific target skill directory.
