# Install Kingdom skill for Codex when Codex config exists

Install the bundled Kingdom skill into Codex when Codex is present.

Behavior:
- Detect Codex by the presence of ~/.codex.
- Install/refresh the skill at ~/.codex/skills/kingdom/SKILL.md with references copied beside it.
- Create ~/.codex/skills/kingdom even when ~/.codex/skills does not already exist.
- Do nothing when ~/.codex is absent.
- Preserve dev-symlink behavior for the specific target skill directory.

## Acceptance Criteria

- [x] install/update writes SKILL.md and references to ~/.codex/skills/kingdom when ~/.codex exists.
- [x] install/update does not create ~/.codex when ~/.codex is absent.
- [x] tests cover Codex install and absent-Codex skip behavior.
