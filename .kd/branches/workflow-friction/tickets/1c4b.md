# Add kd council review as shortcut for code review asks

Add a kd council review command that's essentially kd council ask --new-thread with a built-in prompt tailored for code reviews. Should diff the current branch against base, include the diff in the prompt, and ask the council to review the changes. Saves the user from having to compose the review prompt manually every time.

## Acceptance Criteria

- [x] `kd council review` generates diff against base branch (default: master)
- [x] `--base/-b` flag to specify alternative base branch
- [x] Includes commit log and diff in review prompt
- [x] Supports `--to`, `--async`, `--no-watch`, `--writable` (passthrough to council ask)
- [x] Exits cleanly with message when no diff exists
- [x] Tests cover: diff generation, no-diff exit, prompt content verification
