# council review: send file list instead of raw diff

## Problem

`kd council review` embeds the full `git diff` in the prompt. This wastes context window on raw diff text and hits limits on large PRs. The agents have the files on disk — they can read them.

## Design

Replace the raw diff with a changed-files summary. The prompt becomes:

1. List changed files with line counts (`git diff --stat`)
2. Include commit log for context
3. Ask the agent to read the changed files and review

Prompt template:
```
Review the code changes on this branch vs {base_branch}.

## Changed files
{git diff --stat output}

## Commits
{git log --oneline}

Read the changed files listed above. Review for correctness, edge cases, readability, and potential bugs. Reference file names and line numbers.
```

This is smaller, scales to large PRs, and lets agents use their file-reading tools for full context.

## Acceptance criteria
- [ ] council review sends file list + stats instead of raw diff
- [ ] Commit log still included
- [ ] Diff size warning removed (no longer needed)
