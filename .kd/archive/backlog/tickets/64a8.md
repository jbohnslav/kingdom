# Declare click as a direct runtime dependency

A fresh uv tool install of kingdom-cli 0.6.1 fails on every kd command with ModuleNotFoundError: click. kingdom.cli.council imports click directly, but pyproject.toml declares rich, textual, and typer only; installed typer 0.26.8 no longer declares click. Expected: kd starts after a normal install. Repro: uv tool install --reinstall /path/to/kingdom; kd status. Workaround: reinstall with --with click.
